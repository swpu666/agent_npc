什么情况下才真的调用模型

模型不是"要不要用"的问题，而是"在哪三个口子上用、其余一律不用"的问题。

① 意图兜底分类

规则零信号、或最高分与次高分分差 ≤ 1 时，调用一次四选一受限分类 （temperature=0、max_tokens=40）。它只负责选路，不负责答题。

② 通用理解作答（kb_gap / kb_general）

英雄介绍、强度梯队这类知识库不覆盖的问题，允许模型用自身理解回答； 但必须标注"不在知识库、仅供参考"，且不展示任何来源卡片。

③ 生成阶段

知识问答 / 情境建议 / 闲聊 / 通用作答（kb_gap、kb_general）各调用一次生成； 越界、版本敏感的未收录、缺条件、回顾提问、没听懂五类直接走模板，共 0 次调用。

④ 永不交给模型

数值与规则类问题（刷新秒数、积分算法）模型记忆容易过时， 宁可如实说"未收录"，也不让模型凭印象作答。

优点，以及为此付出的代价

优点

快：意图 + 检索在本地合计约 0.7ms，耗时几乎全在生成上。
可控：每次判级都有证据（命中了哪张表的哪个词），可解释、可回归。
稳：确定性输出，同一输入结果一致，评测与回归才有可比性。
省：实测仅 61.1% 的问答真正调用模型，其余走模板。

代价

覆盖率有天花板：没登记过的说法可能漏判，词表需要持续维护。
误命中更危险：句子碰巧命中某个词或某条正则，规则会"自信地"判错，根本不走模型。
阈值靠经验：分差阈值 1 是人定的，边界会抖动。
字面 ≠ 语义：换个措辞就可能判错，因此每条规则都要配正反用例。

为什么这套适合本场景

话题封闭，且题目对"确定性"有硬要求

本 Agent 被限定在单款游戏、有限话题（对局目标 / 地图机制 / 位置职责 / 基础操作）内， 术语封闭、可枚举——这正是词表方案最擅长的形态；换成开放域助手，词表就会撑不住。 同时题目明确要求"未命中 ≠ 能力范围外"、"不伪造来源"：这类判断必须确定性、可复核 （早期实测把"补条件"的短句判成闲聊、把"没听懂"判成越界，都是交给模型兜底造成的）。 本地规则毫秒级返回，也让"能确定的事不花模型钱"落到了实处。 模型的长处（理解口语）并没有被浪费：它守在兜底分类与 通用作答（kb_gap / kb_general）这两个口子上， 只在该上场时上场。

六个关键设计决策

每一条都对应一个踩过的坑，而不是"看起来很有道理"的空话。

规则优先，模型只是兜底

意图层先走正则与词表打分，命中就 0 次模型调用；不确定先继承上下文，最后才模型兜底。 实测只有 61.1% 的问答真正调用模型，其余（越界 / 版本敏感的未收录 / 需补条件 / 回顾提问 / 没听懂）走确定性模板。

「123456」从花 1.3 秒判成越界，优化为 0ms 拟人化回应

回答的依据强度是分层的

每条回答都标明依据：有知识库依据（带来源卡片）/ 通用理解（kb_gap 与 kb_general， 不展示来源）/未收录（kb_miss，只用于版本敏感数值：如实说不知道）/ 回顾提问 （conversation_recall，复述历史）/没听懂。玩家一眼能看出"这条回答有多可信"。

无资料支持时 citations: []，绝不填占位来源

未命中 ≠ 能力范围外

题目那句"不要把资料未命中判成能力范围外"，落成了两条零降级路径的独立分支： kb_miss（版本敏感的未收录）与 out_of_scope（要求未接入能力）互不转换。

「巅峰赛积分怎么算」如实说未收录，而不是说"这超出我的能力"

评测必须可复核

LLM 评审要逐要点给出原文证据，并逐字校验证据是否真在回答里—— 因为评审模型自己也会编证据。实测把"证据可复核率"从 83.87% 修到 100%。

HTML 报告把回答 / 证据 / 判决并排呈现，可离线抽查

记忆系统，但不越界

会话画像只统计"问了什么"（主题 / 位置 / 英雄），不推断"喜欢玩什么"—— 从"问得多"推"喜欢玩"这一步没有依据，猜错会持续污染后续回答。

跨会话聚合"没答上来"的问题，用真实数据驱动知识库迭代

指标的分母都写死

检索命中率只统计检索层（6 例），不掺生成质量；评审耗时单列、不计入 Agent 耗时； 耗时按"调用模型 / 走模板"分开——混在一起会得出"均值小于 P50"这种不可解释的数字。

每个指标都能回答"这个数字是怎么算出来的"

这些不是"AI 写代码"的炫技，而是"AI 写的代码被我查出来并修掉"的记录，每项都有失败证据。

① S36+ 被归一化成 s36 —— 版本折扣静默失效

归一化把 + 当标点删掉，正则 s(\d+)\+ 永远匹配不上。不报错、不影响其他功能， 只有单测断言能抓住这种"看起来正常其实不生效"的缺陷。

修正：版本号改用只保留 + - ~ 的轻量归一化。

② 评测自身也是需要被验证的产出物

T05 被误判违规——回答引用的"主宰一般在暴君之后被争夺"正是知识库原文，是判分规则不可执行； 评审证据可复核率只有 83.87%，逐条抽查后确认是评审用"……"省略拼接，不是编造。

修正：判分规则量化到可执行 + 新增 judge_note 传达出题意图 + 证据按省略号分段校验。
